# Security policy

The Fiber CLI handles wallet seed material and private keys. Do not include a real `.fiberseed` file, password, seed, private key, RPC credential, or unredacted recovery output in any report.

Report a suspected vulnerability with GitHub's private vulnerability reporting flow from this repository's **Security** tab. Do not open a public issue for a security vulnerability.

Public issues are appropriate for non-sensitive bugs and documentation problems. Use synthetic test data only.
